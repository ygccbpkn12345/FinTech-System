# 最终决策卡片二值结果设计

## 目标

最终决策卡片只展示“买入”或“观望”两种动作，并隐藏该卡片中的仓位信息。

## 范围

- 仅修改 `FinalDecisionCard` 的展示行为。
- “谨慎买入”、英文 `Buy` / `Cautious Buy` 以及其他包含“买入”的动作统一展示为“买入”。
- “观望”、英文 `Hold` 和无法识别的动作统一展示为“观望”。
- 删除最终决策卡片所有布局中的仓位标签与仓位指标。
- 保留底层 `finalDecision.position` 数据，历史记录、决策树、后台反思等其他入口不受影响。
- 置信度、风险评分、核心理由、目标价和止损等现有内容保持不变。

## 实现边界

新增一个无 UI 依赖的展示模型函数，负责动作二值化；`FinalDecisionCard` 使用该函数渲染动作。这样可以用 Node 测试覆盖“谨慎买入 → 买入”和未知动作回退“观望”，同时通过生产构建验证卡片 JSX 删除仓位后仍可编译。

## 验收标准

- 最终决策卡片不出现“谨慎买入”或其他第三种动作。
- 最终决策卡片不出现“仓位”文字或仓位值。
- 历史记录和其他页面仍可读取原始仓位数据。
- 前端测试及生产构建通过。
