# 非阻塞环境模拟与反思流水线设计

## 背景

当前智能分析任务将环境模拟、反思和周度反思纳入同步流水线。用户即使已经看到最终决策，仍需等待这些后处理节点执行完毕；智能分析页面也将这些节点显示为待运行或运行中。对于分析日期为当天的任务，没有后续市场结果可用于复盘，执行反思没有实际意义。

## 目标

- 智能分析以“最终决策完成”为主流程完成边界。
- 最终决策保存成功后立即结束等待，并通过 SSE 返回任务完成状态。
- 智能分析页面不展示环境模拟、反思和周度反思，也不展示反思结果标签页。
- 历史日期的环境模拟和反思在后台执行，结果仅在“反思记忆”页面展示。
- 分析日期为服务器本地当天时，环境模拟、反思和周度反思全部跳过。
- 后台反思失败不得改变已经成功的智能分析状态。

## 非目标

- 不修改五位分析师、路由、经理、风控和最终决策的执行顺序。
- 不改变行情、新闻和基本面数据的抓取逻辑。
- 不为当天任务生成占位反思、模拟反思或周度反思。
- 不在本次改动中引入独立消息队列或新的基础设施。

## 方案选择

采用“主流程提前完成，历史日期后台后处理”的方式。

仅在前端隐藏节点不能缩短后端等待时间；完全移除反思又会丢失历史日期的反思记忆。因此，主分析与反思后处理必须在后端执行边界上分离。

## 后端设计

### 主分析流程

同步主流程保留以下阶段：

1. 五位分析师并行分析。
2. 动态路由。
3. 投资经理决策。
4. 风险经理评估。
5. 最终决策。
6. 保存最终决策及当前完整主分析结果。
7. 将任务状态更新为 `completed`，进度更新为 `100`，发送 SSE `completed` 事件。

主流程完成响应中不要求存在环境模拟或反思结果。结果映射层必须允许 `reflection` 和环境模拟字段缺失，不能为了补齐字段重新等待后台任务。

### 日期判断

以服务器配置时区下的自然日比较 `analysis_date` 与当天日期：

- `analysis_date == today`：不创建环境模拟、反思或周度反思后台任务。
- `analysis_date < today`：主流程完成后提交后台后处理任务。
- `analysis_date > today`：沿用现有分析日期校验，不能进入分析流程。

日期比较使用日期对象，不使用字符串局部比较，也不依据浏览器时区。

### 后台后处理

历史日期任务在最终决策完成后异步执行：

1. 环境模拟。
2. 角色反思与综合反思。
3. 满足原有触发条件时执行周度反思。
4. 构建规范化反思载荷。
5. 原子更新该次分析记录的反思记忆及环境模拟结果。

后台任务使用主流程完成时保存的状态快照，不读取仍可能变化的共享可变状态。后台写入不得覆盖股票信息、分析师报告、路由结果、经理决策、风控结果或最终决策。

在当前单进程部署下，可复用已有受控线程执行器。不得为每次请求创建无上限线程。服务重启时尚未完成的进程内任务可能中断，这是本次不引入持久化任务队列时接受的限制。

### 状态与错误处理

主任务状态只描述主分析：

- 最终决策成功保存：`completed`。
- 最终决策前失败：`failed`。
- 后台环境或反思失败：主任务仍保持 `completed`。

后台后处理应维护独立状态，例如 `not_applicable`、`pending`、`running`、`completed`、`failed`：

- 当天任务记录为 `not_applicable`，原因明确为“当天尚无事后结果，不执行反思”。
- 历史任务提交后为 `pending`，执行时为 `running`。
- 成功写入后为 `completed`。
- 失败时为 `failed`，保存简洁错误信息并写后端日志。

后台状态不得通过智能分析 SSE 作为待完成模块发送。

## 前端设计

### 智能分析页面

实时模块列表仅展示：

- 市场分析师
- 新闻分析师
- 基本面分析师
- 行业分析师
- 动量分析师
- 动态路由
- 投资经理
- 风险经理
- 最终决策

删除环境模拟、反思更新和周度反思模块卡片。工作台删除“反思记忆更新”标签页。收到最终决策后的任务完成事件时，页面立即结束加载状态并展示分析结果。

前端应忽略旧后端或缓存中可能出现的环境与反思模块 SSE 事件，避免重新生成隐藏卡片或改变完成状态。

### 反思记忆页面

反思记忆页面是环境模拟和反思结果的唯一展示入口：

- 历史任务后台完成后，页面读取并展示环境模拟、角色反思、权重调整、经理盲区、风控建议、Prompt 优化及周度反思。
- 后台仍在运行时，显示“反思正在后台生成”，但不影响智能分析页面。
- 后台失败时，显示可重试或检查日志的提示，不把主分析标记为失败。
- 当天任务显示“当天尚无事后结果，本次不执行环境模拟和反思”，不显示虚构内容。
- 若最近一次分析为当天，可继续展示最近一条已完成的历史反思，并明确其股票与分析日期；不能把旧反思误标为当天结果。

## 数据一致性

- 主结果和后台反思通过稳定的分析记录 ID 或任务 ID 关联。
- 后台更新前确认目标记录仍存在。
- 反思写入采用局部合并，避免用旧状态快照覆盖主结果。
- 反思记忆接口返回反思对应的股票代码、分析日期、生成状态和更新时间。
- 前端不得仅凭“最新分析任务”推断反思归属。

## 测试设计

### 后端

- 最终决策完成后，在反思函数被阻塞时，主任务仍立即变为 `completed`。
- 历史日期会提交后台环境与反思任务。
- 当天日期不会调用环境模拟、反思或周度反思。
- 后台反思失败不会将主任务改为 `failed`。
- 后台完成只更新反思相关字段，不覆盖主分析结果。
- 主结果映射在没有反思字段时仍能正常返回。

### 前端

- 智能分析模块列表不包含环境模拟、反思和周度反思。
- 工作台不包含反思记忆更新标签页。
- 最终决策完成事件会结束页面加载。
- 反思记忆页面正确展示后台运行、失败、当天不适用和历史完成四种状态。
- 当天最新分析不会导致历史反思被错误标记为当天生成。

## 验收标准

- 用户在最终决策生成并保存后即可看到完整主分析结果，无需等待反思。
- 智能分析页面不存在环境模拟、反思更新或周度反思的等待卡片与结果标签。
- 历史日期分析完成后，反思可在后台生成并最终出现在反思记忆页面。
- 当天分析不会调用三个后处理节点。
- 后台后处理异常不会破坏主分析结果或完成状态。
